제주대학교 해양수산빅데이터 API

Jeju National University Marine Big Data API

API 문서 (Swagger) API 문서 (ReDoc) DB 스키마 탐색 🤖 AI Analyst

개요

본 API는 연구자 및 학생들에게 AIS 항적 데이터, 수산 데이터를 제공합니다.

  • AIS 항적 데이터: 2012년 ~ 현재 (월별)
  • 수산 데이터: 위판, CPUE, 어획노력량, TAC 등 37개 테이블
  • 어선 정보: 전국 어선 8,698척
  • 수협 관할구역: 139개 수협

사용하려면 회원가입 후 API Key를 발급받아야 합니다.

로그인



회원가입

API Key를 발급받으려면 회원가입이 필요합니다.






시작하기

Python 사용 예시

import requests

API = "http://203.253.202.159:8080"
API_KEY = "jnu_발급받은키"  # 회원가입 시 발급된 키

# AIS 항적 조회
res = requests.get(f"{API}/api/v1/ais/track",
    params={"mmsi": 440137010, "start_date": "2023-01-01", "end_date": "2023-01-07"},
    headers={"X-Api-Key": API_KEY})
data = res.json()
print(f"총 {data['count']}건")

# 수산 데이터 조회
res = requests.get(f"{API}/api/v1/fishery/tables/fish_cpue",
    params={"limit": 100},
    headers={"X-Api-Key": API_KEY})
print(res.json())

curl -H "X-Api-Key: jnu_발급받은키" \

API 엔드포인트

AIS 항적 데이터

GET /api/v1/ais/track — MMSI 기준 항적 조회
GET /api/v1/ais/area — 영역 기준 항적 조회
GET /api/v1/ais/tables — 사용 가능한 데이터 기간

선박 정보

GET /api/v1/ships/fishing — 어선 목록 조회
GET /api/v1/ships/fishing/{mmsi} — 어선 상세 정보
GET /api/v1/ships/cooperatives — 수협 관할구역

수산 데이터

GET /api/v1/fishery/tables — 사용 가능한 테이블 목록
GET /api/v1/fishery/tables/{table_name} — 테이블 데이터 조회
GET /api/v1/fishery/tables/{table_name}/schema — 테이블 스키마

인증

POST /api/v1/auth/register — 회원가입
POST /api/v1/auth/login — 로그인 (JWT)
GET /api/v1/auth/me — 내 정보

사용 예시

Python

import requests

# 특정 선박 항적 조회
url = "http://203.253.202.159:8000/api/v1/ais/track"
params = {
    "mmsi": 440137010,
    "start_date": "2023-06-01",
    "end_date": "2023-06-07",
    "limit": 5000
}
response = requests.get(url, params=params)
data = response.json()

print(f"총 {data['count']}건")
for row in data['data'][:5]:
    print(f"  {row['datetime']} | ({row['lat']:.4f}, {row['lon']:.4f}) | SOG={row['sog']}kn")

영역 조회

# 울산 앞바다 영역 조회

lat위도도 (degrees)
lon경도도 (degrees)
sog대지속력knots

제한 사항

  • 요청당 최대 100,000건
  • 영역 조회 시 기간을 7일 이내로 권장
